# About
This project executes a simulation that shows the execution of the protocols on the physics layer and link layer of the network.

## Physics layer
- This simulation shows the most basic signal modulation techniques output on a function graph;
- The user can choose which signal modulation to view;

## Link layer
- This simulation shows the output of different bits encapsulation techniques and error correction techniques;
- The user can can choose which technique to use;
- The effects of noise on the raw bits can be simulated by increasing the chance of a bit flip.  

## Dependencies
- GCC compiler
- GTK library

## How to run this project
On linux, execute the following commands on the project's root directory:

```$ mkdir bin```

```$ make```
